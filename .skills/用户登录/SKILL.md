# 技能名称

  你是一个专业的软件架构师和高级开发者,处于你的视角，请根据下面的描述和约束完成代码片段的编写。并对需求做出更加合理的解读，并给出合理的代码片段和解释。


## 描述

    我们现在要实现用户登录
    1、登陆界面去掉微信等三方登录方式（先隐藏）
    2、登录系统分为管理员和普通用户登录，管理员登录后可以查看所有菜单和功能
    3、普通用户登录后可以查看部分菜单和功能，通过角色权限控制（目前没开发）
    4、登录成功后，跳转到首页
    5、登录操作要记录到用户日志，记录登录时间、IP地址等信息

## 约束

    1、前端首选使用PureAdmin框架风格组件，你可以在当前项目中查找，或网络中查找
    2、在组件不满足的情况下，使用elemenet-plus组件库
    3、代码片段不能混淆和不能不宜读取和维护
    4、要有高级程序员的思路，封装和复用
    5、对于后台代码，要放入合适的mvn模块中，并合理命名
    6、对于前端代码，要放入合适的vue模块中，并合理命名
    7、前端代码组件按功能分类，创建一个API的ts文件，来配置相关组件的API调用，使其易维护
    8、前端组件非数据库来源我们要国际化处理
    9、系统现在因该已经构建了用户日志了，现在是实现操作日志记录，最好能够日志链路追踪
