# 后端接口配置快速指南

## 🚀 快速开始

### 第一步：选择配置方式

**方式 A：使用环境变量（推荐）**
```bash
# 1. 复制示例配置
cp .env.example .env.local

# 2. 编辑 .env.local，修改后端地址
VITE_API_BASE_URL=http://localhost:8080
VITE_API_PROXY_TARGET=http://localhost:8080
```

**方式 B：直接修改配置文件**
```typescript
// 编辑 src/config/index.ts
export const apiConfig = {
  baseURL: "http://localhost:8080",  // 修改这里
  timeout: 10000,
};
```

### 第二步：重启开发服务器

```bash
# 停止当前服务器 (Ctrl+C)
# 重新启动
npm run dev
```

## 📝 常用配置

### 场景 1：后端在 8080 端口（默认）- 直接连接

`.env.development`：
```env
# 前端直接请求后端（需要后端配置 CORS）
VITE_API_BASE_URL=http://localhost:8080
```

### 场景 2：后端在 8080 端口 - 使用代理（推荐）

`.env.development`：
```env
# 前端请求代理路径
VITE_API_BASE_URL=/api

# 代理转发到后端
VITE_API_PROXY_TARGET=http://localhost:8080
```

### 场景 3：后端在其他端口

`.env.development`：
```env
# 直接连接
VITE_API_BASE_URL=http://localhost:9090

# 或使用代理
VITE_API_BASE_URL=/api
VITE_API_PROXY_TARGET=http://localhost:9090
```

### 场景 4：后端在其他机器

`.env.development`：
```env
# 直接连接
VITE_API_BASE_URL=http://192.168.1.100:8080

# 或使用代理
VITE_API_BASE_URL=/api
VITE_API_PROXY_TARGET=http://192.168.1.100:8080
```

### 场景 5：生产环境

`.env.production`：
```env
# 生产环境使用相对路径，通过 Nginx 代理
VITE_API_BASE_URL=/api
# 不需要配置 VITE_API_PROXY_TARGET
```

## 🔐 两种连接方式对比

### 方式 1：直接连接

```env
VITE_API_BASE_URL=http://localhost:8080
```

**优点**：
- 配置简单
- 不需要额外的代理配置

**缺点**：
- 可能遇到 CORS（跨域）问题
- 需要后端配置允许跨域

**适用场景**：
- 后端已配置 CORS
- 快速测试

### 方式 2：使用代理（推荐）

```env
VITE_API_BASE_URL=/api
VITE_API_PROXY_TARGET=http://localhost:8080
```

**优点**：
- 避免跨域问题
- 更接近生产环境
- 可以统一请求路径

**缺点**：
- 需要配置代理

**适用场景**：
- 正常开发流程
- 模拟生产环境

## ⚠️ 注意事项

1. **修改环境变量后必须重启开发服务器**
2. **`.env.local` 文件不会被提交到 Git**，适合存放个人配置
3. **使用代理模式时**：
   - `VITE_API_BASE_URL` 设置为 `/api`
   - `VITE_API_PROXY_TARGET` 设置为实际后端地址
   - Vite 会自动将 `/api` 请求转发到后端
4. **生产环境不需要配置代理**，由 Nginx 等服务器处理
5. **`vite.config.ts` 已自动读取 `VITE_API_PROXY_TARGET`**，无需手动修改
