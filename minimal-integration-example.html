🚀 踢出通知功能 - 最简单的集成方法

只需 3 步，即可在您的应用中集成踢出通知功能！

1引入脚本文件

将 kickout-notification.js 文件放到您的项目中，然后在 HTML 中引入：

<script src="/js/kickout-notification.js"></script>

建议放在 </body> 标签之前。

2登录成功后初始化

在用户登录成功后，调用初始化方法：

// 登录成功回调 function onLoginSuccess(token) { // 保存 token localStorage.setItem('satoken', token) // 🎯 初始化踢出通知（关键代码） window.KickOutManager.init() // 跳转到首页 window.location.href = '/home' }

3退出登录时清理

用户主动退出时，清理管理器：

// 退出登录 function onLogout() { // 清理踢出通知管理器 window.KickOutManager.destroy() // 清除 token localStorage.removeItem('satoken') // 跳转到登录页 window.location.href = '/login' }

✨ 完整示例

<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>我的应用</title> </head> <body> <div id="app"> <h1>欢迎</h1> <button onclick="logout()">退出登录</button> </div> <!-- 引入踢出通知脚本 --> <script src="/js/kickout-notification.js"></script> <script> // 检查是否已登录 const token = localStorage.getItem('satoken') if (token) { // 已登录，初始化踢出通知 window.KickOutManager.init() } else { // 未登录，跳转到登录页 window.location.href = '/login' } // 退出登录 function logout() { window.KickOutManager.destroy() localStorage.removeItem('satoken') window.location.href = '/login' } </script> </body> </html>

❓ 常见问题

Q: 弹窗没有显示？

A: 打开浏览器控制台（F12），查看是否有错误信息。确认 localStorage 中有 satoken。

Q: 如何自定义弹窗样式？

A: 直接修改 kickout-notification.js 中的样式代码。

Q: 支持 Vue/React/Angular 吗？

A: 完全支持！请查看 KICKOUT-INTEGRATION-GUIDE.md 中的详细示例。
