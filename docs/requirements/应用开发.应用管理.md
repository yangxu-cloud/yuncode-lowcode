# 应用开发管理需求

> 来源：skills/应用开发/SKILL.md + SKILL-应用管理.md（两文件内容相同，合并去重）

## 概述

"应用开发"作为一级菜单，下设：应用管理、业务建模、定时任务、系统服务。

## 应用管理

页面横向 tab 切换：应用管理、应用安装、应用升级、应用卸载、应用日志。

### 应用管理 tab

**头部按钮**：
- 刷新按钮
- 新建应用按钮 → 弹出新建页面
- 搜索框：搜索应用 ID 和应用名称

**新建应用**：
- 字段：应用名称、应用图标、应用 ID、应用描述
- ID 生成规则：`com.yuncode.user.apps.yun{年月日6位伪随机数}`，其中 `com.yuncode.user.apps` 固定，后面可自定义
- 确认后自动创建应用目录结构：

```
apps/install/{appId}/
├── pom.xml              # parent = yuncode-lowcode-boot
├── manifest.xml         # 应用描述信息（参考模板）
├── icon.png             # 应用图标
├── lib/                 # 私有依赖 JAR
├── repository/          # 数据库表、表单、台账、定时任务、流程
├── template/            # 扩展 Controller 页面模板
└── web/                 # 静态资源（HTML/CSS/JS）
```

目录管理：
- `apps/install/` — 新建和上传的应用
- `apps/uninstall/` — 卸载的应用归档
- `apps/history/` — 历史版本归档

**应用列表**：
- 表头：应用名、信息、时间、运行状态

### 应用安装 tab

**头部按钮**：
- 刷新按钮
- 本地应用上传（`.app` 文件）
- 一键安装所有未安装的 App

**安装列表**：
- 表头：待安装应用、版本、发布时间、状态
- 操作：安装 / 取消
- 安装完成的列表自动移除
