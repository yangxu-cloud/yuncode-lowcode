# 导航管理需求

> 来源：skills/导航管理/SKILL.md

## 概述

导航管理菜单挂在"公共设施"下，采用左右双面板布局。

## 左侧面板

1. 树形结构展示菜单层级
2. 顶部搜索框：搜索菜单
3. "新建子系统"按钮
4. 菜单层级设计：
   - 第一层：大分类（如"办公"）
   - 第二层：业务分类（如"常用"、"工具"、"通讯录"）
   - 第三层：详细功能（如"流程中心"、"邮件"、"网盘"）
5. 默认菜单：办公 → 常用（流程中心、邮件、网盘）/ 通讯录（单位通讯录、个人通讯录）
6. 节点操作按钮（hover 显示）：添加（十字）、编辑（笔状）、更多（下拉：是否可见、上移、下移、删除）
7. 菜单默认收起，只展开"办公"下的子级

## 右侧面板

1. 选中节点后显示三个按钮：添加权限、权限追加到下级
2. 下方表格：类型（角色/人员/部门）、名称、描述

## 权限控制

1. 租户管理员可管理本租户导航，admin 可管理所有租户
2. 租户新建菜单与租户 ID 挂钩，子级继承父级租户
3. 默认导航对所有租户可见

## 组件选择器

1. 菜单分为三类：系统菜单（系统管理型）、用户菜单（业务性）、自定义
2. 选择组件时带出路由路径（组件路径去掉 index.vue）
3. 系统管理员可选择系统组件，租户管理员不可选
4. 选择系统组件 → 菜单归属自动设为"系统菜单"

## 其他要求

1. 图标选择：Element Plus 图标库，开发专用图标选择组件
2. 路由方式：路由配置表 + 动态加载，开发可视化组件选择器
3. 排序方式：拖拽排序 + 上移下移按钮
4. 接口加入 API 文档，操作记录日志
