# 平台架构要求

> 来源：skills/平台要求/SKILL.md（已去敏，去重）

## 概述

构建一个 SaaS 低代码平台，关注设计模式和效率，使用 SaaS 系统该有的技术栈。

## 技术选型

| 维度 | 要求 |
|------|------|
| 后端框架 | Spring Boot（可扩展为微服务架构） |
| 前端框架 | PureAdmin（vue-pure-admin 轻量版），不足时使用 Element Plus |
| 权限认证 | Sa-Token + JWT（无状态） |
| 通知机制 | SSE（前端订阅后端推送事件） |
| 代码规范 | 参考阿里 Java 开发规范 |
| 开发约束 | 不使用完全限定类名，讨论输出使用中文 |

## SaaS 安全规范

- **访问层安全**：网络访问控制、API 鉴权（防重放、防注入）、Web 安全检查
- **服务层安全**：网络区域逻辑隔离、主机加固、入侵检测
- **数据安全**：加密传输、隐私保护、租户退租时彻底擦除数据
- **安全管理**：统一身份鉴别、安全审计日志、密钥管理

## 系统管理要求

1. 三类日志：用户日志、系统日志、操作日志，支持链路追踪
2. 在线用户管理：查看在线用户、踢出操作
3. 链路追踪：MDC + SkyWalking Agent
4. 日志检索与导出

## 系统监控要求

1. 服务器监控：主机信息、JVM 内存、系统内存、CPU、网络、磁盘
2. 数据库监控
