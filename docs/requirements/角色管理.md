# 角色管理需求

> 来源：skills/角色管理/SKILL.md

## 概述

角色管理菜单挂在"公共设施"下，采用左右双面板布局。

## 左侧面板

1. 树形结构：根节点"角色" → 角色分类 → 角色详情
2. 搜索框：搜索角色
3. 默认角色分类"用户"，下设：普通用户、系统管理员、租户管理员
4. 节点操作按钮（hover 显示）：编辑、添加、删除

## 右侧面板

选中节点后以 tab 页显示：
1. **基本信息 tab**：名称、分类、角色代码、描述
2. **人员 tab**：该角色下的人员列表
3. **部门 tab**：该角色下的部门
4. **权限 tab**：已分配的权限列表

## 权限控制

1. 租户管理员管理本租户角色，系统管理员管理所有
2. 租户新建角色与租户 ID 挂钩，子级继承
3. 菜单默认收起，只展开"角色"下的角色分类

## 角色编辑

1. 角色分类支持选择已有或手动输入（不存在则自动创建）
2. 根节点"角色"添加时，分类可选可填
3. 从分类节点添加角色时，自动带入分类名称且不可编辑
4. 编辑表单使用 Drawer 抽屉模式
