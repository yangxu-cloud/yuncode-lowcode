# 应用开发.业务建模-新建-新建业务数据库需求

> 来源：应用开发.业务建模-新建-新建业务数据库

## 概述
应用开发.业务建模-新建-新建业务数据库
该功能是为了搜先低代码的前置处理，用户可以通过前台页面操作后台数据库的变化，而不用业务人员操作复杂的sql去服务器操作

### 应用页面布局

**布局**：

- 应用开发.业务建模-新建-新建业务数据库.html

**功能描述**：
- 新建业务数据库中的立即新建后，弹出新建业务数据库页面，用户填完后，在后台创建表
- 新建的业务表，包含默认字段如下：
  - **工作流字段**（用于流程引擎和主子表关联）：ID,PROCESSINSTID,ORGID,CREATEDATE,CREATEUSER,UPDATEDATE,UPDATEUSER,PROCESSDEFID,ISEND,TASKINST_HANDLEUSER,TASKINST_NODENAME
  - **审计字段**（用于数据审计和租户隔离）：DELETE_BY,DELETE_FLAG,DELETE_TIME,TENANT_ID
- 共15个默认字段，这些BO默认字段是通过前台插件BO的必要条件
- 点击确认的时候，你需要检查下该分类下有没有数据库表，没有的话，在概述边上再建一个存储页签，里面是创建BO列表，同时创建一个页签打开数据库表设计页面，参考：应用开发.业务建模-BO创建.html
```
apps/install/{appId}/
├── pom.xml              # parent = yuncode-lowcode-boot
├── manifest.xml         # 应用描述信息（参考模板）
├── icon.png             # 应用图标
├── lib/                 # 私有依赖 JAR
├── repository/          # 数据库表、表单、台账、定时任务、流程
├── template/            # 扩展 Controller 页面模板
└── web/                 # 静态资源（HTML/CSS/JS）
```

目录管理：
- `apps/install/` — 新建和上传的应用
- `apps/uninstall/` — 卸载的应用归档
- `apps/history/` — 历史版本归档

**应用列表**：
- 表头：应用名、信息、时间、运行状态
