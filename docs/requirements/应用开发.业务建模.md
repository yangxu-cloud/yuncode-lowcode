# 应用开发.业务建模需求

> 来源：应用开发.业务建模

## 概述
应用开发.业务建模
业务建模功能是让开发者能够自己创建BO数据库表，表单，以及流程，视图台账，图表，关联选择的能力

### 应用页面布局

**布局**：

- 大体上布局参考应用开发.业务建模.html

**功能描述**：
- 布局中微应用下应该放的是启动的应用
- 鼠标移动到应用名上显示一个添加添加，删除，编辑操作，都为图表按钮
- 点击添加可以添加一个分类，分类层级最多两级，删除就是删除分类，编辑修改分类名。一个应用下可以有很多分类，但是分类下最多再建一个层级的分类，两级指的是除了应用层级外，树形最多三个层级
- 当点击一个应用时，默认统计当前应用下数据库表，表单，以及流程，视图台账，图表的个数，和应用信息
- 当点击一个分类时，默认统计该分类下数据库表，表单，以及流程，视图台账，图表的数量
- 当点击一个分类时，默认显示的统计，他还有几个默认页签存储管理，表单管理，流程管理，视图管理，字典管理。该分类页签下有数据时显示分类，没有就不显示了

# 存储管理
- 分类下无 BO → 存储管理页签隐藏，用户从概述页签的"新建"按钮创建
- 创建第一个 BO 后 → stats 刷新 → 存储管理页签自动出现，并自动切换到该页签
- 有 BO 时 → 存储管理页签显示，可管理/设计/删除
- 删完最后一个 BO → stats 刷新 → 自动切回概述页签，存储管理页签隐藏
```
apps/install/{appId}/
├── pom.xml              # parent = yuncode-lowcode-boot
├── manifest.xml         # 应用描述信息（参考模板）
├── icon.png             # 应用图标
├── lib/                 # 私有依赖 JAR
├── repository/          # 数据库表、表单、台账、定时任务、流程
├── template/            # 扩展 Controller 页面模板
└── web/                 # 静态资源（HTML/CSS/JS）
```

目录管理：
- `apps/install/` — 新建和上传的应用
- `apps/uninstall/` — 卸载的应用归档
- `apps/history/` — 历史版本归档

**应用列表**：
- 表头：应用名、信息、时间、运行状态
