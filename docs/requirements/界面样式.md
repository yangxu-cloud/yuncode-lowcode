# 界面样式与系统配置需求

> 来源：skills/平台界面样式/SKILL.md

## 概述

系统配置包括主题模式、主题色、菜单布局、页宽、页签风格等，参考 PureAdmin 系统配置功能。

## 已实现的组件

1. **搜索组件** — 全局搜索对话框（600px），Ctrl+K / Cmd+K 打开，ESC 关闭，结果分组
2. **消息通知组件** — 实时徽标（99+）、通知/消息/待办三 tab、未读蓝点、全部标已读/清空
3. **全屏组件** — 一键全屏/退出，图标自动切换
4. **主题切换组件** — 亮色/暗色切换，图标切换（太阳/月亮），localStorage 持久化
5. **设置面板组件** — 右侧抽屉（300px），主题色选择器、灰色模式、色弱模式、布局设置
6. **面包屑导航** — 自动显示当前路径，点击跳转
7. **用户下拉菜单** — 头像、用户名、租户信息、个人中心、退出确认
8. **语言切换** — 多语言支持

## 补充要求

1. 主题模式应包含浅色模式
2. 主题色与主题是并列的分类关系
