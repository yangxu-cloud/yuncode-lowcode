# 组织服务需求

> 来源：skills/组织服务/SKILL.md

## 概述

组织服务菜单挂在"公共设施"下，采用左右双面板布局。

## 左侧树形面板

1. 展示系统组织架构树，同时显示人员信息
2. 节点类型：company（公司）、department（部门）、user（人员）
3. 搜索框（树顶部）：搜索组织和人员
4. 顶层默认节点"组织架构"
5. "组织架构"下只能添加公司/集团
6. 公司节点下只能添加部门
7. 操作按钮：编辑、新增（下拉：添加子部门/添加人员）、更多
8. 添加表单使用 Drawer 抽屉
9. 支持节点拖拽移动，自动计算排序号

## 右侧面板

### 点击部门节点
1. **基础信息 tab**：显示直接子级数据（含直接人员），有添加按钮（选择添加部门/人员）
2. **所有人员 tab**：显示该部门下所有人员（含孙子节点）

### 点击人员节点
1. **基础信息 tab**：人员信息，操作按钮（冻结/解冻、编辑、删除）
2. **兼职部门 tab**：显示兼职部门信息（含岗位和角色）
3. **权限 tab**：菜单权限勾选保存

## 人员管理

1. 密码使用可配置的默认密码，用户首次登录时提示修改
2. 用户表添加字段：`department_id`（主部门）、`is_leader`（是否主部门领导）
3. 兼职关系存 `sys_user_org` 表
4. 添加兼职部门时不可跨租户
5. 兼职部门移除只移除对应关系，不影响其他组织关系

## 租户与组织关系

| 角色 | 权限 |
|------|------|
| 平台管理员 (PLATFORM_ADMIN) | 添加公司（创建租户）、查看所有租户数据，tenant_id=0 |
| 租户管理员 (TENANT_ADMIN) | 管理本租户组织/用户/角色，不可创建租户 |
| 普通用户 (NORMAL) | 按角色权限访问功能 |

## 数据接口要求

1. 定义统一的数据接口，将组织数据和人员数据转换为标准树结构
2. 部门选择通用组件：左右两列（左：部门树，右：常用信息），支持租户过滤、多选/单选
3. 接口加入 API 文档，操作记录日志
