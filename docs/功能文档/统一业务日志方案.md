# 统一业务日志方案

## 📋 概述

本文档描述了项目的统一业务日志记录方案，使用 AOP 切面 + 注解的方式，自动记录登录日志、操作日志和系统日志。

**实施日期**: 2024-01-20
**改造范围**: 登录服务、操作日志、系统日志
**改造文件数**: 6个核心文件

---

## 🎯 设计目标

1. **自动化日志记录**: 使用 AOP 切面自动记录，无需手动调用
2. **统一日志管理**: 三个日志表职责清晰，互不重复
3. **减少代码冗余**: Service 层专注业务逻辑，不关心日志记录
4. **完整上下文信息**: 自动记录用户信息、请求信息、链路追踪信息
5. **灵活可扩展**: 通过注解参数自定义日志内容

---

## 📊 日志表设计

### 1. sys_login_log（登录日志）

**用途**: 记录用户登录成功/失败信息

**字段**:
- `tenant_id`: 租户ID
- `username`: 用户名
- `login_time`: 登录时间
- `status`: 登录状态（0=成功，1=失败）
- `msg`: 登录消息
- `ipaddr`: IP地址
- `login_location`: 登录地点
- `browser`: 浏览器
- `os`: 操作系统
- `cost_time`: 登录耗时（毫秒）
- `trace_id`: 链路追踪ID

**使用注解**: `@LoginLog(loginType = "tenant")`

---

### 2. sys_operation_log（操作日志）

**用途**: 记录用户的CRUD操作、权限变更等

**字段**:
- `tenant_id`: 租户ID
- `tenant_name`: 租户名称
- `user_id`: 用户ID
- `username`: 用户名
- `module`: 模块名称
- `operation`: 操作描述
- `method`: 方法全路径
- `params`: 请求参数
- `ip`: IP地址
- `location`: 地点
- `user_agent`: 用户代理
- `execute_time`: 执行时长（毫秒）
- `status`: 状态（success/error）
- `error_msg`: 错误信息
- `trace_id`: 链路追踪ID

**使用注解**: `@OperLog(module = "用户管理", businessType = 1, description = "新增用户")`

**businessType 取值**:
- `0`: 其它
- `1`: 新增
- `2`: 修改
- `3`: 删除
- `4`: 授权
- `5`: 导出
- `6`: 导入

---

### 3. sys_system_log（系统日志）

**用途**: 记录系统异常、性能监控等

**字段**:
- `tenant_id`: 租户ID
- `tenant_name`: 租户名称
- `user_id`: 用户ID
- `username`: 用户名
- `level`: 日志级别（TRACE, DEBUG, INFO, WARN, ERROR）
- `module`: 模块名称
- `message`: 日志消息
- `exception`: 异常类名
- `stack_trace`: 堆栈跟踪
- `trace_id`: 链路追踪ID
- `tags`: 自定义标签（JSON格式）
- `created_at`: 创建时间

**使用注解**: `@SystemLog(module = "订单模块", description = "创建订单", level = "INFO")`

## 🔧 实施方案

### 方案一：登录日志（AOP 自动记录）

#### 1. 添加注解

```java
@Service
public class TenantLoginService {

    @LoginLog(loginType = "tenant")
    public LoginVO login(LoginDTO loginDTO, HttpServletRequest request) {
        // 只需关注业务逻辑，无需手动记录日志
        // ...

        return loginVO;
    }
}
```

#### 2. AOP 自动处理

`LoginLogAspect` 会自动：
- ✅ 捕获方法参数（username）
- ✅ 记录成功/失败状态
- ✅ 计算登录耗时
- ✅ 记录用户信息和请求信息
- ✅ 记录链路追踪信息

#### 3. 改造对比

**Before（手动记录）**:
```java
public LoginVO login(LoginDTO loginDTO, HttpServletRequest request) {
    Long startTime = System.currentTimeMillis();
    Integer status = LoginStatus.SUCCESS.getCode();
    String msg = "登录成功";

    try {
        // 业务逻辑
        // ...
    } catch (BusinessException e) {
        status = LoginStatus.FAIL.getCode();
        msg = e.getMessage();
        throw e;
    } finally {
        // 手动记录日志
        Long costTime = System.currentTimeMillis() - startTime;
        sysLoginLogService.recordLoginLog(tenantId, username, status, msg, request, costTime);
    }
}
```

**After（AOP 自动记录）**:
```java
@LoginLog(loginType = "tenant")
public LoginVO login(LoginDTO loginDTO, HttpServletRequest request) {
    try {
        // 业务逻辑
        // ...
        return loginVO;
    } catch (BusinessException e) {
        throw e;  // AOP 会自动记录失败状态
    }
}
```

**优势**:
- ✅ 代码减少 50%+
- ✅ 无需维护 status、msg 等变量
- ✅ 统一的日志格式
- ✅ 自动捕获异常

### 方案二：操作日志（AOP 自动记录）

#### 1. 添加注解

```java
@RestController
@RequestMapping("/system/user")
public class SysUserController {

    @OperLog(module = "用户管理", businessType = 1, description = "新增用户")
    @PostMapping
    public Result<Void> add(@RequestBody SysUser user) {
        userService.insertUser(user);
        return Result.success();
    }

    @OperLog(module = "用户管理", businessType = 2, description = "修改用户")
    @PutMapping
    public Result<Void> edit(@RequestBody SysUser user) {
        userService.updateUser(user);
        return Result.success();
    }

    @OperLog(module = "用户管理", businessType = 3, description = "删除用户")
    @DeleteMapping("/{userId}")
    public Result<Void> remove(@PathVariable Long userId) {
        userService.deleteUser(userId);
        return Result.success();
    }
}
```

#### 2. AOP 自动处理

`OperLogAspect` 会自动：
- ✅ 记录操作类型（新增、修改、删除）
- ✅ 记录请求参数和返回结果
- ✅ 记录操作状态（成功/失败）
- ✅ 记录执行时长
- ✅ 记录用户和租户信息
- ✅ 记录 IP、浏览器等信息

---

### 方案三：系统日志（AOP 自动记录）

#### 1. 现有机制

项目已有 `SystemLogAspect`，自动拦截所有 Controller 层的异常：

```java
@Aspect
@Component
public class SystemLogAspect {

    @Pointcut("execution(* com.yuncode..controller..*.*(..))")
    public void controllerPointcut() {}

    @Around("controllerPointcut()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        try {
            return joinPoint.proceed();
        } catch (Throwable e) {
            // 自动记录异常到 sys_system_log
            recordSystemLog(e);
            throw e;
        }
    }
}
```

#### 2. 自定义系统日志

对于需要特殊记录的方法，可以使用 `@SystemLog` 注解：

```java
@SystemLog(module = "订单模块", description = "处理大额订单", level = "WARN")
public void processLargeOrder(OrderDTO dto) {
    // AOP 会自动记录到 sys_system_log
}
```

## 🔍 日志查询

### 查询登录日志

```sql
-- 查询最近失败的登录记录
SELECT * FROM sys_login_log
WHERE status = 1
ORDER BY login_time DESC
LIMIT 10;

-- 查询某用户的所有登录记录
SELECT * FROM sys_login_log
WHERE username = 'admin'
ORDER BY login_time DESC;
```

### 查询操作日志

```sql
-- 查询删除操作
SELECT * FROM sys_operation_log
WHERE operation LIKE '%删除%'
ORDER BY created_at DESC;

-- 查询某用户的操作记录
SELECT * FROM sys_operation_log
WHERE username = 'admin'
ORDER BY created_at DESC;
```

### 查询系统日志

```sql
-- 查询 ERROR 级别的日志
SELECT * FROM sys_system_log
WHERE level = 'ERROR'
ORDER BY created_at DESC;

-- 根据 TraceId 查询完整的调用链
SELECT * FROM sys_system_log
WHERE trace_id = 'xxx'
ORDER BY created_at;
```
