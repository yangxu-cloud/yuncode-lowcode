## 1. 概述

### 1.1 设计目标

平台日志处理方案旨在提供一个**统一、高效、可追溯**的日志管理机制，主要实现以下目标：

- **自动化记录**：通过 AOP 切面自动记录关键操作，无需手动编写日志代码
- **分类管理**：登录日志、操作日志、系统日志三大类，职责清晰
- **完整上下文**：自动记录用户信息、请求信息、链路追踪信息
- **性能监控**：记录方法执行耗时，发现性能瓶颈
- **异常追踪**：完整记录异常堆栈，便于问题定位
- **链路追踪**：集成 TraceId/SpanId，实现分布式调用链追踪

### 1.2 日志分类

| 日志类型 | 表名 | 用途 | 主要字段 |
|---------|------|------|---------|
| **登录日志** | `sys_login_log` | 记录用户登录/登出行为 | username, status, ipaddr, browser, os, cost_time |
| **操作日志** | `sys_operation_log` | 记录用户 CRUD 操作 | module, operation, method, params, status, execute_time |
| **系统日志** | `sys_system_log` | 记录系统异常和性能问题 | level, module, message, exception, stack_trace, trace_id |

## 4. AOP 切面实现

### 4.1 登录日志切面 (LoginLogAspect)

**位置**: `com.yuncode.system.aspect.LoginLogAspect`

**功能**: 自动记录带有 `@LoginLog` 注解的方法调用

**实现要点**:

```java
@Aspect
@Component
public class LoginLogAspect {

    @Around("@annotation(com.yuncode.system.annotation.LoginLog)")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();

        // 1. 获取方法参数
        Object[] args = joinPoint.getArgs();
        String username = extractUsername(args);
        HttpServletRequest request = extractRequest(args);

        // 2. 初始化登录状态
        Integer status = LoginStatus.SUCCESS.getCode();
        String msg = "登录成功";

        try {
            // 3. 执行登录方法
            Object result = joinPoint.proceed();
            return result;

        } catch (BusinessException e) {
            // 4. 业务异常（登录失败）
            status = LoginStatus.FAIL.getCode();
            msg = e.getMessage();
            throw e;

        } catch (Exception e) {
            // 5. 系统异常
            status = LoginStatus.FAIL.getCode();
            msg = "系统异常：" + e.getMessage();
            throw new BusinessException(e.getMessage());

        } finally {
            // 6. 记录登录日志（无论成功或失败）
            long costTime = System.currentTimeMillis() - startTime;
            loginLogService.recordLoginLog(
                tenantId, username, status, msg, request, costTime
            );
        }
    }
}
```

**使用示例**:

```java
@Service
public class TenantLoginService {

    @LoginLog(loginType = "tenant")
    public LoginVO login(LoginDTO loginDTO, HttpServletRequest request) {
        // 只需关注业务逻辑，无需手动记录日志
        // ...
        return loginVO;
    }
}
```

### 4.2 操作日志切面 (OperLogAspect)

**位置**: `com.yuncode.system.aspect.OperLogAspect`

**功能**: 自动记录带有 `@OperLog` 注解的方法调用

**实现要点**:

```java
@Aspect
@Component
public class OperLogAspect {

    @Around("@annotation(com.yuncode.system.annotation.OperLog)")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();

        // 1. 获取注解信息
        OperLog operLog = getAnnotation(joinPoint);

        // 2. 创建操作日志对象
        SysOperationLog operationLog = new SysOperationLog();
        operationLog.setModule(operLog.module());
        operationLog.setOperation(getBusinessTypeName(operLog.businessType()) + ":" + operLog.description());
        operationLog.setMethod(getMethodName(joinPoint));

        // 3. 设置用户信息和租户信息
        fillUserInfo(operationLog);

        // 4. 记录请求参数
        fillRequestParams(operationLog, joinPoint.getArgs());

        // 5. 设置链路追踪信息
        fillTraceInfo(operationLog);

        try {
            // 6. 执行方法
            Object result = joinPoint.proceed();
            operationLog.setStatus("success");
            return result;

        } catch (Exception e) {
            // 7. 记录异常
            operationLog.setStatus("error");
            operationLog.setErrorMsg(e.getMessage());
            throw e;

        } finally {
            // 8. 计算执行时间并保存
            operationLog.setExecuteTime(System.currentTimeMillis() - startTime);
            operationLog.setCreatedAt(LocalDateTime.now());
            operationLogService.recordOperationLog(operationLog);
        }
    }
}
```

**业务类型枚举**:

```java
public enum BusinessType {
    OTHER(0, "其它"),
    INSERT(1, "新增"),
    UPDATE(2, "修改"),
    DELETE(3, "删除"),
    GRANT(4, "授权"),
    EXPORT(5, "导出"),
    IMPORT(6, "导入");
}
```

**使用示例**:

```java
@RestController
@RequestMapping("/system/user")
public class SysUserController {

    @DeleteMapping("/{userId}")
    public Result<Void> remove(@PathVariable Long userId) {
        userService.deleteUser(userId);

}
```

### 4.3 系统日志切面 (SystemLogAspect)

**位置**: `com.yuncode.system.aspect.SystemLogAspect`

**功能**:
1. 自动拦截所有 Controller 层的异常并记录到系统日志
2. 记录带有 `@SystemLog` 注解的方法调用

**实现要点**:

```java
@Aspect
@Component
public class SystemLogAspect {

    @Pointcut("execution(* com.yuncode..controller..*.*(..))")
    public void controllerPointcut() {}

    @Around("controllerPointcut()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        try {
            return joinPoint.proceed();
        } catch (Throwable e) {
            // 自动记录异常到 sys_system_log
            recordSystemLog(e, joinPoint);
            throw e;
        }
    }

    private void recordSystemLog(Throwable e, ProceedingJoinPoint joinPoint) {
        SysSystemLog systemLog = new SysSystemLog();

        // 设置日志级别
        systemLog.setLevel(e instanceof BusinessException ? "WARN" : "ERROR");

        // 设置异常信息
        systemLog.setException(e.getClass().getSimpleName());
        systemLog.setStackTrace(getStackTrace(e));

        // 设置模块信息
        systemLog.setModule(joinPoint.getTarget().getClass().getSimpleName());

        // 保存日志
        systemLogService.save(systemLog);
    }
}
```

**使用示例**:

```java
@Service
public class OrderService {

    @SystemLog(module = "订单模块", description = "处理大额订单", level = "WARN")
    public void processLargeOrder(OrderDTO dto) {
        // 业务逻辑
    }
}
```

## 5. 链路追踪机制

### 5.1 TraceId 生成与传播

**TraceId 生成器**: `TraceIdContext`

```java
public class TraceIdContext {

    private static final ThreadLocal<String> TRACE_ID = new ThreadLocal<>();
    private static final ThreadLocal<String> SPAN_ID = new ThreadLocal<>();
    private static final ThreadLocal<String> PARENT_SPAN_ID = new ThreadLocal<>();

    // 生成唯一的 TraceId
    public static String generateTraceId() {
        return UUID.randomUUID().toString().replace("-", "");
    }

    // 创建子 Span
    public static void createChildSpan() {
        String traceId = getTraceId();
        String parentSpanId = getSpanId();

        setTraceId(traceId != null ? traceId : generateTraceId());
        setParentSpanId(parentSpanId);
        setSpanId(generateSpanId());
    }
}
```

### 5.2 链路追踪切面

**位置**: `com.yuncode.common.aspect.TraceIdAspect`

**功能**: 自动为 Service、Controller、Mapper 层的方法调用创建子 Span

```java
@Aspect
@Component
public class TraceIdAspect {

    @Around("execution(* com.yuncode..service..*.*(..)) || " +
            "execution(* com.yuncode..controller..*.*(..)) || " +
            "execution(* com.yuncode..mapper..*.*(..))")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        // 创建子 Span
        TraceIdContext.createChildSpan();

        String className = joinPoint.getTarget().getClass().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        long startTime = System.currentTimeMillis();

        try {
            Object result = joinPoint.proceed();

            // 性能监控
            long costTime = System.currentTimeMillis() - startTime;
            if (costTime > 3000) {
                log.warn("方法执行过慢: {}.{} | 耗时: {}ms | TraceId: {} | SpanId: {}",
                    className, methodName, costTime,
                    TraceIdContext.getTraceId(),
                    TraceIdContext.getSpanId());
            }

            return result;

        } catch (Exception e) {
            log.error("方法异常: {}.{} | TraceId: {} | SpanId: {}",
                className, methodName,
                TraceIdContext.getTraceId(),
                TraceIdContext.getSpanId(), e);
            throw e;
        }
    }
}
```

## 6. 日志记录策略

### 6.1 登录日志记录策略

| 场景 | 是否记录 | 记录内容 |
|------|---------|---------|
| 用户登录成功 | ✅ | username=xxx, status=0, msg="登录成功" |
| 密码错误 | ✅ | username=xxx, status=1, msg="密码错误" |
| 账号不存在 | ✅ | username=xxx, status=1, msg="账号不存在" |
| 验证码错误 | ✅ | username=xxx, status=1, msg="验证码错误" |
| 账号被锁定 | ✅ | username=xxx, status=1, msg="账号已锁定" |
| 系统异常 | ✅ | username=xxx, status=1, msg="系统异常：xxx" |

### 6.2 操作日志记录策略

| 操作类型 | 是否记录 | 记录内容 |
|---------|---------|---------|
| 新增 (INSERT) | ✅ | 记录新增对象的字段值（params） |
| 修改 (UPDATE) | ✅ | 记录修改前后的字段值 |
| 删除 (DELETE) | ✅ | 记录删除对象的 ID |
| 查询 (SELECT) | ❌ | 一般不记录（查询日志过多） |
| 导出 (EXPORT) | ✅ | 记录导出条件和导出条数 |
| 导入 (IMPORT) | ✅ | 记录导入文件名和导入结果 |

### 6.3 系统日志记录策略

| 级别 | 触发条件 | 示例 |
|------|---------|------|
| ERROR | Controller 层抛出异常 | NullPointerException、SQLException |
| WARN | 业务异常、性能警告 | 订单金额过大、方法执行时间>3秒 |
| INFO | 重要业务节点 | 订单创建成功、支付成功 |
| DEBUG | 调试信息 | 方法入参、返回值（需手动配置） |
| TRACE | 最详细的跟踪信息 | 每个 SQL 语句（需手动配置） |

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.error(e.getMessage());
    }

    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        // 记录到系统日志
        log.error("系统异常", e);

        // 返回友好提示
        return Result.error("系统异常，请联系管理员");
    }
}
```

## 8. 性能优化

### 8.1 异步日志记录

使用 Spring `@Async` 异步保存日志，避免阻塞主线程：

```java
@Service
public class SysOperationLogService {

    @Async
    public void recordOperationLog(SysOperationLog operationLog) {
        try {
            // 异步保存到数据库
            this.save(operationLog);
        } catch (Exception e) {
            // 日志记录失败不影响主业务
            log.error("保存操作日志失败", e);
        }
    }
}
```

### 8.2 批量插入

对于高并发场景，可以使用批量插入提升性能：

```java
@Service
public class SysOperationLogService {

    private final List<SysOperationLog> buffer = new ArrayList<>();

    @Scheduled(fixedDelay = 5000) // 每5秒执行一次
    public void flushBuffer() {
        if (buffer.isEmpty()) {
            return;
        }

        try {
            // 批量插入
            saveBatch(buffer);
            buffer.clear();
        } catch (Exception e) {
            log.error("批量插入操作日志失败", e);
        }
    }
}
```

### 8.3 参数截断

避免过长的参数影响性能：

```java
String params = objectMapper.writeValueAsString(args);
operationLog.setParams(params.length() > 2000 ? params.substring(0, 2000) : params);
```

## 10. 监控告警

### 10.1 日志监控指标

| 指标 | 告警阈值 | 处理方式 |
|------|---------|---------|
| ERROR 级别日志 | 5分钟内>10条 | 钉钉/企业微信通知 |
| 登录失败次数 | 同一IP 5分钟内>5次 | 自动封禁 IP |
| 方法执行时间 | 单次>3秒 | 记录慢查询日志 |
| 数据库连接池 | 空闲连接<10% | 钉钉告警 |

### 10.2 慢查询监控

```java
@Aspect
@Component
public class SlowQueryAspect {

    @Around("execution(* com.yuncode..mapper..*.*(..))")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();

        try {
            return joinPoint.proceed();
        } finally {
            long costTime = System.currentTimeMillis() - startTime;

            // 记录慢查询
            if (costTime > 1000) {
                String methodName = joinPoint.getSignature().getName();
                log.warn("慢查询: {} | 耗时: {}ms | TraceId: {}",
                    methodName, costTime, TraceIdContext.getTraceId());

                // 保存到系统日志
                recordSlowQuery(methodName, costTime);
            }
        }
    }
}
```

### 10.3 登录异常监控

```java
@Service
public class LoginMonitorService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    public void checkLoginFailure(String ip, String username) {
        String key = "login:fail:" + ip;

        // 增加失败次数
        Long count = redisTemplate.opsForValue().increment(key);
        redisTemplate.expire(key, 5, TimeUnit.MINUTES);

        // 超过5次，记录告警
        if (count == 5) {
            log.warn("检测到登录异常: ip={}, username={}", ip, username);

            // 发送告警通知
            sendAlert("登录异常告警", String.format("IP: %s, 失败次数: %d", ip, count));
        }
    }
}
```

### B. 常用 SQL 查询

```sql
-- 1. 查询最近失败的登录记录
SELECT * FROM sys_login_log
WHERE status = 1
ORDER BY login_time DESC
LIMIT 10;

-- 2. 查询某用户的操作记录
SELECT
    module,
    operation,
    execute_time,
    status,
    created_at
FROM sys_operation_log
WHERE username = 'admin'
ORDER BY created_at DESC
LIMIT 20;

-- 3. 查询 ERROR 级别的系统日志
SELECT
    level,
    module,
    message,
    exception,
    created_at
FROM sys_system_log
WHERE level = 'ERROR'
ORDER BY created_at DESC
LIMIT 50;

-- 4. 根据 TraceId 查询完整调用链
SELECT '登录' as type, username, msg, trace_id, span_id
FROM sys_login_log
WHERE trace_id = 'xxx'

UNION ALL

SELECT '操作' as type, username, operation, trace_id, span_id
FROM sys_operation_log
WHERE trace_id = 'xxx'

UNION ALL

SELECT '系统' as type, username, message, trace_id, span_id
FROM sys_system_log
WHERE trace_id = 'xxx'
ORDER BY span_id;

-- 5. 统计各模块的操作次数
SELECT
    module,
    COUNT(*) as count,
    AVG(execute_time) as avg_time
FROM sys_operation_log
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY module
ORDER BY count DESC;
```
