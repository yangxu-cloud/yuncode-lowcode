# 国际化语言切换方案

## 概述

Yuncode LowCode 平台基于 Vue I18n v11 实现了完整的中英文双语支持，包括菜单、路由、表单、按钮等所有界面元素的国际化。

## 技术栈

- **Vue I18n v11** (`vue-i18n`) - 国际化核心库
- **Composition API** - 使用 `useI18n()` composable
- **响应式语言切换** - 基于 Vue 3 reactive system

## 核心配置

### 1. i18n 实例配置

文件位置：`yuncode-pure-admin/src/locales/index.ts`

```typescript
import { createI18n } from "vue-i18n";
import zhCN from "./zh-CN";
import enUS from "./en-US";

const messages = {
  "zh-CN": zhCN,
  "en-US": enUS
};

// 安全地获取 localStorage 中的语言设置
const getInitialLocale = () => {
  try {
    return localStorage.getItem("locale") || "zh-CN";
  } catch {
    return "zh-CN";
  }
};

const i18n = createI18n({
  legacy: false,             // 使用 Composition API 模式
  locale: getInitialLocale(), // 默认语言
  fallbackLocale: "zh-CN",   // 备用语言
  fallbackRoot: true,        // 在找不到翻译时回退到根语言
  globalInjection: true,     // 全局注入 $t、$rt、$d 等方法
  missingWarn: false,        // 禁用缺失翻译警告
  fallbackWarn: false,       // 禁用回退警告
  messages
});

export default i18n;
```

**关键配置说明：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `legacy` | `false` | 启用 Composition API 模式，使用 `useI18n()` 而非 `this.$t()` |
| `globalInjection` | `true` | 在模板中全局可用 `$t()` 方法 |
| `fallbackRoot` | `true` | 翻译缺失时回退到根级语言 |
| `missingWarn` | `false` | 不显示缺失翻译的警告 |

## 语言切换实现

### 1. 语言切换组件

文件位置：`yuncode-pure-admin/src/layout/components/lay-sidebar/components/SidebarLanguage.vue`

```vue
<script setup lang="ts">
import { computed, onMounted, watch } from "vue";
import { useI18n } from "vue-i18n";

const { locale } = useI18n();

// 支持的语言列表
const languages = [
  { label: "简体中文", value: "zh-CN" },
  { label: "English", value: "en-US" }
];

// 当前语言（使用 locale 的值）
const currentLanguage = computed(() => locale.value);

// 初始化语言
onMounted(() => {
  const savedLocale = localStorage.getItem("locale");
  if (savedLocale && (savedLocale === "zh-CN" || savedLocale === "en-US")) {
    locale.value = savedLocale;
  } else {
    locale.value = "zh-CN";
  }
});

// 切换语言
const changeLanguage = (lang: string) => {
  locale.value = lang;
};

// 监听 locale 变化，同步到 localStorage
watch(locale, (newLocale) => {
  localStorage.setItem("locale", newLocale);
});
</script>

<template>
  <el-dropdown trigger="click" @command="changeLanguage">
    <span class="language-dropdown">
      <IconifyIconOffline :icon="Translation" />
    </span>
    <template #dropdown>
      <el-dropdown-menu>
        <el-dropdown-item
          v-for="lang in languages"
          :key="lang.value"
          :command="lang.value"
          :class="{ 'is-active': currentLanguage === lang.value }"
        >
          {{ lang.label }}
        </el-dropdown-item>
      </el-dropdown-menu>
    </template>
  </el-dropdown>
</template>
```

**关键实现点：**

1. **响应式当前语言** - 使用 `computed` 获取当前语言
2. **持久化存储** - 监听 locale 变化并同步到 localStorage
3. **初始化读取** - 组件挂载时从 localStorage 读取语言设置

## 组件内国际化

### 1. 模板中使用 `$t()`

```vue

    <h3>{{ $t('settings.basicConfig') }}</h3>
    <p>{{ $t('settings.basicDesc') }}</p>

    <el-form-item :label="$t('settings.systemName')">
      <el-input :placeholder="$t('settings.inputSystemName')" />
    </el-form-item>

    <el-button @click="handleSave">
      {{ $t('settings.saveSettings') }}
    </el-button>
  </div>
</template>
```

### 2. Script 中使用 `t()`

```vue
<script setup lang="ts">
import { useI18n } from "vue-i18n";

const { t } = useI18n();

// 验证消息
const rules = {
  systemName: [
    { required: true, message: t('settings.systemNameRequired'), trigger: "blur" }
  ]
};

// 动态消息
const handleSave = () => {
  ElMessage.success(t('settings.saved'));
};
</script>
```

## 最佳实践

### 1. 命名规范

- **使用点号分隔的命名空间**：`settings.systemName`
- **使用有意义的名称**：避免使用 `text1`、`msg2` 等
- **保持一致性**：相似功能使用相似的前缀

### 2. 翻译文本规范

- **保持简洁**：按钮文本尽量简短
- **使用专业术语**：技术术语保持一致性
- **考虑上下文**：翻译要符合使用场景

### 3. 性能优化

- **按需加载**：大型应用可考虑按语言包懒加载
- **缓存翻译**：已加载的语言包会被缓存
- **避免重复翻译**：相同的文本使用相同的 key

### 4. 开发建议

```typescript
// ✅ 推荐：使用翻译 key
<el-button>{{ $t('common.save') }}</el-button>

// ❌ 避免：硬编码文本
<el-button>保存</el-button>

// ✅ 推荐：在 script 中使用 t()
ElMessage.success(t('settings.saved'));

// ❌ 避免：在 script 中硬编码
ElMessage.success('保存成功');
```

## 常见问题

### Q1: 切换语言后文本没有更新？

**A:** 检查以下几点：

1. 确认 `globalInjection: true` 已配置
2. 确认路由的 `meta.title` 使用的是 i18n key（如 `"routes.home"`）
3. 确认菜单组件使用了 `getTitle()` 函数

### Q2: 如何翻译动态内容？

**A:** 使用插值语法：

```typescript
// 翻译文件
welcome: "欢迎, {name}!"

// 组件中使用
$t('welcome', { name: '张三' })
```

### Q3: 如何处理复数形式？

**A:** 使用 Vue I18n 的复数语法：

```typescript
// 翻译文件
apple: 'no apples | one apple | {count} apples'

// 组件中使用
$tn('apple', 0)  // no apples
$tn('apple', 1)  // one apple
$tn('apple', 5)  // 5 apples
```

### Q4: 验证消息如何国际化？

**A:** 在 `setup` 中使用 `t()` 函数：

```typescript
const { t } = useI18n();

const rules: FormRules = {
  username: [
    { required: true, message: t('login.usernameRequired'), trigger: "blur" }
  ]
};
```
